## 当前实现

- 每个 Companion ID 独立存储记忆。兼容升级原有 SQLite 表，保留旧数据；旧条目标记为手动确认。
- 不设固定记忆总数上限，管理界面每页 30 条，查询最多 100 条/页，使用按角色和更新时间的数据库索引。单条主题 1–40 字符、内容 1–200 字符。
- 检索在角色范围内由数据库按主题、有限同义词、类别和意图关键词评分；精确主题优先，相关的标记重要记忆有有限排序加成，无关重要记忆不注入。归档、过期与非代表性同义项不引用。最多取 48 个候选，再按实际 JSON UTF-8 字节预算选择（最多 2,400 字节、12 条安全上限），不固定四条；上下文构建器再次执行预算及状态校验。这不是 Qwen tokenizer 的精确 Token 计数，也不是完整语义向量检索。
- 独立的自动形成开关和云端检索开关均按角色保存、默认关闭。开启自动形成后，在新用户消息成功持久化时本地提取，不要求逐条确认，无额外 AI 请求，不扫描旧聊天。
- 当前自动提取采用有限白名单与明确第一人称陈述语法，覆盖普通饮食、音乐、兴趣、色彩偏好（支持明确的最喜欢、感兴趣、现在更喜欢、不再喜欢、并列对象和部分过去/现在对比陈述）。问题、假设、第三人称、复杂或超出白名单的内容拒绝提取。白名单并非通用敏感数据检测器；不得把其描述为完整自然语言理解。
- 自动记录从实际持久化的同角色 user 消息取得，保存分类、来源、来源消息 ID 和 explicit_statement 证据等级；不使用 assistant 生成的内容作为事实。共同经历另有 observed_exchange 证据等级与回复 ID，只证明对话发生。来源 ID 仅供定位，删除历史后来源消息可能不可用，不复制完整消息。
- 同主题重复内容不新增；较新的明确用户陈述可更新自动记录的旧偏好与来源 ID，不自动覆盖手动确认记录。当前对话陈述始终优先。每角色持久化已处理消息 ID 游标，防止旧消息回放覆盖新记忆或复活删除项；删除后用户重新明确陈述仍可产生新记忆。历史/现在对比仅提取当前陈述，不推断未明示的旧偏好反转。有限同义词组归一化（阅读/看书/读书等），新自动记忆使用统一主题；旧数据库迁移将重复自动项归档，保留全部原始行，手动确认优先，不擅自合并两个手动条目。检索同一组只选择一项，以手动确认优先、最新证据为准；归档或过期的代表项不会回退到旧同义项。恢复旧归档项不覆盖更新的代表项。跨主题复杂冲突和完整历史版本仍待实现。
- 管理窗口支持分页、查看、补充、同主题修改、删除、清空、来源标记、重要程度、归档/恢复、有效 30 天及永久有效。新自动偏好（含明确交流偏好）默认 180 天有效，重复明确陈述续期；旧记录不批量设过期日期。手动设置的期限（包括永久有效）不会被自动观察改写；主动归档项不会被自动提取恢复。过期项保留可查，不再参与检索；恢复将清除过期时间。手动新建记忆默认永久有效。手动修改将记录标记为用户确认。手动管理不是形成普通记忆的必要步骤。
- 聊天历史与记忆分别管理；删除记忆不撤回过去云端请求或包含该事实的历史回复。关闭自动形成不清空已有记忆；关闭检索不清除历史。自动形成仅本机处理；只有单独开启检索，相关记忆才加入 Qwen 请求。普通聊天仍按现有协议发送近期上下文。
- 数据库未额外加密，请勿保存密码、凭据等敏感信息。记忆异常不阻断普通聊天；无 Qwen Key 时可管理记忆并查询本地时间。

## M4-B4 首个增量：经历和交流偏好

- 用户经历：仅识别有限词库的明确第一人称里程碑陈述（如完成学习计划、读完一本书、学会游泳），按主题和来源消息 UTC 记录日保存。保留“用户表示”的证据性质，不推断实际事件日期、结果或现实行为。相同主题/记录日可能合并；不复制原文、不收集敏感字段、不扫描旧消息。
- 共同经历：有限普通请求词库（如学习计划、阅读计划、书籍推荐）；仅在有效 AI 回复已成功写入历史之后记录，数据库再次验证同角色、同会话相邻 user/assistant 消息。只保存主题、UTC 记录日、用户和回复 ID 及固定描述，不提取助手声称的现实事实、任务结果或答案细节。按主题/记录日去重，单独持久化回复游标防重放。历史删除后来源 ID 可能不可查。
- 交流偏好：识别明确的回复长短、表达方式、表情符号等请求，允许较新自动记录更新；人工确认仍受保护。仅在话题相关且授权检索时作为参考，不直接改变基础人格、也不推断情绪、依赖或关系亲密程度。M4-B5 的独立成长授权允许重复明确反馈缓慢形成有限表达倾向。
- 用户经历及共同经历默认不设有效期，但可由用户归档、删除或设置有效期；交流偏好沿用 180 天默认策略。日期为 UTC 记录日，不代表发生地或用户实际事件日。
- 检索增加经历主题片段、有限问法和交流偏好类别匹配；仅对有限追问表达继承同一会话上一条用户问题，其他新问题不继承，仍按角色、授权、状态和 JSON 预算筛选。未接入向量模型或精确 tokenizer。
- 自动形成与发送相关记忆的授权仍独立且默认关闭；无额外模型调用。原自动记忆授权范围扩展到上述本机类别，界面更新说明。无后台扫描；记忆模块本身不改写人格。两轮内容均待实际 Windows 界面验收。

## M4-B5 首个增量：渐进表达倾向

- 独立 SQLite 表 companion_growth_settings、companion_growth_axes、companion_growth_changes 按稳定 Companion ID 隔离成长数据。原始基础人格、avatar persona 以及保留的 evolving_personality_json 字段不修改；当前成长表为唯一实际成长状态来源。
- 维度：回复详略（-2 至 +2）、直接表达、自然表达、表情克制（0 至 2）。只识别固定明确交流反馈，不使用 AI 回复、聊天频率、情绪推断、身份、价值观或亲密度评分。
- 独立授权默认关闭；开启允许本地学习以及正常 Qwen 请求中应用简短派生倾向，并用于本地关怀措辞。与记忆形成、记忆检索两个开关相互独立；不新增 AI 请求，不发送成长历史、来源 ID 或证据计数。
- 新持久化用户消息才可作为证据。每维度需至少三个不同 UTC 日期的同方向反馈，在 60 天窗口内累计，每次调整一级；同日重复不累计，矛盾反馈清除待累计证据，回复详略可由反向反馈渐进回退。调整不超过两级。已处理消息游标防重放，授权切换跳过既有历史并清除待累计证据。
- 聊天上下文只增加固定表达参考，基础人格、用户当前要求、事实与任务完整性优先。关怀提醒可在简洁/直接倾向下采用较短的角色化措辞，不改变触发条件、天气事实或来源署名。
- 伙伴记忆窗口新增成长人格入口，展示状态及最近 50 条调整。暂停停止学习和应用但保留状态；撤销最近一次调整恢复此前分数并清除待累计证据；重置删除全部成长分数、成长历史和待累计证据，保留开关和消息游标。重置不修改记忆或聊天记录。
- 成长记录与长期记忆、聊天历史独立，删除记忆/历史不自动清除已经派生的成长倾向；如需清除使用成长重置。已发送给 Qwen 的内容无法撤回。仅保存分数、日期、来源消息 ID，不复制原文。
- 现阶段仅为基于明确交流反馈的有界适配，并非完整自主性格演化，不包含行为画像。阈值与时间窗口为初始产品策略。

## M4-B6 第二增量：开放词汇与语义查询扩展

上一增量 Windows CI 200/200 通过，0 警告、0 错误。开放词汇采用独立默认关闭授权，须先开启自动记忆；只接受明确第一人称的食物、饮料、音乐类型、运动、休闲活动、颜色偏好，限定 2–12 个汉字的对象，拒绝有限敏感和不确定词。无需对象预设于词库，保存实际用户陈述与来源 ID，证据等级 open_explicit_statement。此筛选并非完备的隐私检测，不适合私人信息。原有手动确认保护、有效期、归档和去重保持。
