# M4-B — 本地长期记忆第一增量

M4-A Windows 本机验收由用户决定延后；其状态仍为待验收。M4-B 开始独立开发，不代表 M4-A 已验收。

## 范围

- 在现有 companions.db 中新增独立的 companion_memories 与 companion_memory_preferences 表，按稳定 Companion ID 隔离，保持既有表和数据不变。
- 聊天窗口“伙伴记忆 · 管理”入口：用户明确创建主题与内容、按同主题更新、查看、删除或清空。无 Qwen Key 也可管理。
- 每角色最多 200 条、每主题 2–40 字符、内容最多 200 字符。列表有界，检索匹配当前消息中的主题，优先较具体（较长）主题，最多 4 条。不是语义向量检索。
- 相关记忆发送给 Qwen 默认关闭，用户按角色单独启用/暂停。记忆内容作为参考数据加入有限上下文，不作为指令。时间离线回答不走记忆检索。
- 聊天历史与记忆分别管理，删除一方不自动删除另一方；已经进入历史或发送到云端的内容不因此撤回。数据库属于本机用户，未额外加密；请勿保存凭据等敏感信息。
- 记忆存储或查询失败不阻断普通聊天；不会在启动、后台或管理界面发起 AI 请求。
- 修复已有聊天初始化时无 Key 禁用输入的问题，使本机时间查询可直接使用。

## 后续增量

自动形成候选记忆（仅有来源可追溯的用户陈述，需明确授权和审查）、冲突和时效处理、相关性提升、共同经历摘要、缓慢且可回滚的人格成长。当前未自动学习用户行为或改写人格。

## 验收

验证重启持久化、角色隔离、默认不检索、启用/暂停、相关主题匹配和上限、更新删除、与历史独立以及无 API Key 管理。Windows GUI 与真实 Qwen 仍需用户本机验收。
